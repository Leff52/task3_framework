## Что реализовано

 **Чтение конфигурации из трех источников** с явным порядком приоритета:
- Файл (`appsettings.json`)
- Переменные окружения (`PR3_*` для C#, `APP_*` для Node.js)
- Аргументы командной строки (`--mode`, `--origins`, и т.д.)

 **Ранняя валидация конфигурации** перед запуском - приложение не запустится с неправильными параметрами

 **CORS с доверенными источниками** - запросы только от разрешённых источников

 **Rate limiting** - ограничение частоты запросов для защиты от DDoS

 **Защитные заголовки** для снижения рисков XSS и другие:
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Cache-Control: no-store, max-age=0`
- `Pragma: no-cache`

 **Два режима работы**:
- **Учебный** - подробные сообщения об ошибках
- **Боевой** - минимальные сообщения, безопасность на первом месте

 **Полные тесты** для обеих проектов

## Режимы работы

### Учебный (по умолчанию)

```json
{"code": "bad_request", "message": "Поле name не должно быть пустым", "requestId": "abc123"}
```

Содержит полную информацию об ошибке для диагностики.

### Боевой

```json
{"code": "bad_request", "message": "Ошибка обработки запроса", "requestId": "abc123"}
```

Скрывает деталь ошибок в целях безопасности.

## Ключевые особенности архитектуры

1. **Fail-fast** - приложение не запустится с Bad конфигурацией
2. **Visibility** - четкие сообщения об ошибках в консоль
3. **Security by default** - консервативные настройки по умолчанию
4. **Configurable** - все параметры настраиваются без изменения кода
5. **Testable** - полное покрытие тестами

## Параметры конфигурации

| Параметр | Тип | Описание | Обязателен | По умолчанию |
|----------|-----|---------|-----------|------------|
| `Mode` | string | Учебный или Боевой | ✅ | Учебный |
| `TrustedOrigins` | string[] | Доверенные CORS источники | ✅ (не пусто) | - |
| `ReadPerMinute` | int | Лимит GET запросов/мин | ✅ (>0) | 60 |
| `WritePerMinute` | int | Лимит POST запросов/мин | ✅ (>0, ≤Read) | 20 |

## Валидация конфигурации

При запуске приложение проверяет:

```javascript
✓ TrustedOrigins не пуста
✓ TrustedOrigins содержат валидные URL с http/https
✓ ReadPerMinute > 0
✓ WritePerMinute > 0
✓ WritePerMinute ≤ ReadPerMinute
✓ Mode равен "Учебный" или "Боевой"
```

Если какая-то проверка не passou, приложение:
```
 Не запускается
 Выводит ошибки в консоль
 Вызывает exit(1)
```

## Пример использования

Запуск в боевом режиме с пользовательскими лимитами:

**C#:**
```bash
dotnet run -- --mode=Боевой --readPerMinute=1000 --writePerMinute=500
```

**Node.js:**
```bash
APP_MODE=боевой APP_READ_PER_MINUTE=1000 APP_WRITE_PER_MINUTE=500 npm start
```

## Безопасность

-  CORS ограничивает запросы только от доверенных источников
-  Rate limiting защищает от DDoS атак
-  Защитные заголовки снижают риски XSS и Clickjacking
-  Режимы работы скрывают детали ошибок в production
-  Валидация конфигурации предотвращает неправильные settings
