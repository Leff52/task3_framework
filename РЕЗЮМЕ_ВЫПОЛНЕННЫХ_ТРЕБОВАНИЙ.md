### 3. Ограничение запросов от доверенных источников

**C#** - [Program.cs](csharp/src/Pr3.ConfigAndSecurity/Program.cs#L40-L49)
```csharp
builder.Services.AddCors(cors =>
{
    cors.AddPolicy("TrustedOrigins", policy =>
    {
        policy.WithOrigins(options.TrustedOrigins)
              .AllowAnyHeader()
              .AllowAnyMethod();
    });
});
```

**Node.js** - [security.js](node/src/security.js#L7-L18)
```javascript
export function applyCors(req, res, trustedOrigins) {
  const origin = req.headers.origin;
  if (!origin) return;
  if (trustedOrigins.includes(origin)) {
    res.setHeader("Access-Control-Allow-Origin", origin);
    res.setHeader("Access-Control-Allow-Methods", "GET,POST,OPTIONS");
  }
}
```

### 6. Два режима работы (Учебный и Боевой)

**C#** - [AppMode.cs](csharp/src/Pr3.ConfigAndSecurity/Config/AppMode.cs) + [ErrorHandlingMiddleware.cs](csharp/src/Pr3.ConfigAndSecurity/Middlewares/ErrorHandlingMiddleware.cs#L34)
```csharp
public enum AppMode { Учебный, Боевой }

private string ToClientMessage(string msg)
    => _options.Mode == AppMode.Учебный 
        ? msg 
        : "Ошибка обработки запроса";
```

**Node.js** - [server.js](node/src/server.js#L83-L86)
```javascript
const msg = mode === "учебный" 
    ? String(e?.message ?? "Ошибка") 
    : "Ошибка обработки запроса";
```

**Учебный режим:** Подробное сообщение об ошибке
Боевой режим:** Минимальное сообщение "Ошибка обработки запроса"

Переключение **только через конфигурацию** без изменения кода.

##  Как убедиться, что всё работает

### Запуск C# проекта

```bash
cd csharp/src/Pr3.ConfigAndSecurity

# Запустится в учебном режиме (настройки по умолчанию)
dotnet run

# Или с переопределением
dotnet run -- --mode=Боевой --readPerMinute=100

# Тесты
cd ../../../tests/Pr3.ConfigAndSecurity.Tests
dotnet test
```

### Запуск Node.js проекта

```bash
cd node
npm install
npm start

# С переопределением
APP_MODE=боевой APP_READ_PER_MINUTE=100 npm start

# Тесты
npm test
```

### Проверка функциональности

1. **Попробовать запустить с пустым TrustedOrigins:**
   ```bash
   dotnet run -- --origins=""
   ```
   Ожидается: ошибка и отказ в запуске

2. **Превысить лимит запросов:**
   ```bash
   for i in {1..100}; do curl -H "Origin: http://localhost:5173" http://localhost:3000/api/items; done
   ```
   После 60-го запроса должны получить 429

3. **Проверить защитные заголовки:**
   ```bash
   curl -v http://localhost:3000/api/items | grep -i "X-Frame-Options\|X-Content-Type"
   ```
